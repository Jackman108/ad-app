# Бизнес-модель: «Завхоз на аутсорсе»

**Обновлено:** 04.11.2026  
**Статус:** канон продукта после [ADR 0004](../adr/0004-product-pivot-zavhoz.md)  
**Источник:** бриф владельца (mesh, 04.11.2026)

Платформа на стыке **маркетплейса услуг** и **фасилити-менеджмента**: единое окно и генподряд для коммерческих точек + технологическая диспетчеризация мастеров (ИП / самозанятые НПД). Регион старта: **РБ**, валюта **BYN**.

## 1. Value Proposition

### Бизнес-клиенты (кофейни, ритейл, офисы)

| Боль | Обещание |
| --- | --- |
| Наличка «мужику с Куфара» | Безнал с р/с, закрывающие (акты / ЭДО) |
| Простой точки | On-demand выезд 1–2 ч (приоритет по подписке — быстрее) |
| Много подрядчиков | Один рамочный договор с платформой |
| Качество | Фильтр мастеров, разбор споров на стороне платформы |

### Мастера

| Боль | Обещание |
| --- | --- |
| Дешёвый C2C | Коммерческие заказы (+40–70% к квартирным чекам, ориентир) |
| Логистика | Заказы по гео (свой/соседний район) |
| Бюрократия юрлиц | Легальный B2B-доход через платформу |
| Маркетинг | Платформа приводит спрос |

## 2. Monetization

1. **Комиссия с заказа (старт):** 15–25% (ориентир 20%). Клиенту — фикс по прайсу; мастер получает долю; остальное — маржа платформы.
2. **Подписка / retainer** для сетей: фикс BYN/объект/мес → приоритет выезда, плановый аудит, пакет нормо-часов; сверх лимита — по тарифу со скидкой.
3. **Наценка на материалы:** 10–15% при перевыставлении чеков запчастей.

Юнит-пример (ориентир из брифа): чек 120 BYN → мастер 96 (80%) → вал платформы 24 → минус эквайринг/инфра ≈ **~21 BYN** опер. прибыли до налога платформы. При ~15 заказах/день по городу — порядка **~9.5k BYN/мес** опер. (грубый сценарный расчёт, не KPI).

## 3. Cost structure

- **Постоянные:** VPS/домен (~80–120 BYN), банк/эквайринг, налоги/ФСЗН.
- **Переменные:** B2B-продажи/маркетинг, SMS/пуши, юр. аудит оферт.
- Без собственного склада, автопарка и закупа инструментов на старте.

## 4. Операционный цикл (автоматизация)

```text
Клиент: заявка + фото/видео
    → категория + цена (прайс / алгоритм)
    → пуш мастерам в радиусе
    → мастер принимает и выезжает
    → фото «после» + отчёт
    → клиент подтверждает / акт
    → списание с баланса / оплата
```

## 5. Запуск без «миллионов» (продуктовый MVP)

Из брифа (ops-first), адаптировано под наш стек (ADR 0001):

| Шаг | Суть | В репозитории |
| --- | --- | --- |
| 1 | Юр. фундамент: ИП + оферты клиент/мастер | Вне кода; ссылки в docs позже |
| 2 | Техстарт: заявки, кабинеты, диспетчер | **Next/Prisma** вместо Tilda как целевой путь |
| 3 | База мастеров (Минск/центр): 3+3+3 роли | Справочник Master + верификация |
| 4 | Партизанский B2B: 20–30 точек на рамочный договор | CRM-процесс; в продукте — Org/Site |

**Не в первом вертикальном срезе:** полный ЭДО, эквайринг, подписки сетей, ML-категоризация, нативные мобильные приложения.

## 6. Масштаб (после PMF)

Клининг коммерции, картриджи, кондиционеры и др. — экосистема вокруг того же объекта (Site) и того же цикла заявки.

## 7. Связь с кодом Объявки BY

Переиспользуем: auth, upload фото, Region/Locality BY, паттерны FSM/DTO/use-case, in-app сообщения как задел чата клиент↔диспетчер/мастер.  
Не переносим как продукт: ленту объявлений, избранное seller/buyer C2C, «горячую» ленту S8.
