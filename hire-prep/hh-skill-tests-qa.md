## Офлайн-банк (самоподготовка под темы 674 Средний)

Разминка до старта — не экранная шпаргалка в живом тесте.

### Объекты и массивы

| Вопрос | Ответ |
|--------|--------|
| `==` vs `===` | `===` без coercion |
| Spread / rest | Spread раскрывает; rest собирает |
| `Object.assign` / `{...obj}` | Shallow copy |
| `Object.keys` / `values` / `entries` | Массивы ключей / значений / пар |
| `Array.map` / `filter` / `reduce` | Преобразование / отбор / свёртка |
| `find` vs `filter` | find — первый или undefined; filter — массив |
| `slice` vs `splice` | slice — копия диапазона; splice — мутация |
| `sort` без компаратора | Строковое сравнение (для чисел нужен `(a,b)=>a-b`) |
| `Map` vs объект | Любые ключи; size; итерация предсказуема |
| `Set` | Уникальные значения |
| Деструктуризация + default | `const { a = 1 } = obj`; `const [x, ...rest] = arr` |
| Optional chaining / nullish | `a?.b`, `x ?? y` (только null/undefined) |
| `JSON.stringify` и `undefined` | В объекте ключ пропускается; в массиве → `null` |
| Сравнение объектов | По ссылке; deep — вручную / lib |

### Работа с сетью

| Вопрос | Ответ |
|--------|--------|
| `fetch` и HTTP 404 | Не throw; `response.ok === false` |
| Когда throw у fetch | Сеть / abort / CORS fail на уровне сети |
| CORS preflight | OPTIONS при не-simple запросах |
| `async/await` + fetch | `const r = await fetch(...); const data = await r.json()` |
| `Promise.all` vs `allSettled` | all — fail-fast; allSettled — все статусы |
| Query string | `URLSearchParams` / ручная сборка |
| Idempotent методы | GET/PUT/DELETE обычно; POST — нет |
| JSON Content-Type | `application/json` + `JSON.stringify` тела |

### Наследование и замыкания

| Вопрос | Ответ |
|--------|--------|
| Замыкание | Функция + лексическое окружение создания |
| Замыкание в цикле `var` | Все итерации делят одну переменную → `let` / IIFE |
| `this` у стрелки | Лексический; у `function` — от call-site |
| `call` / `apply` / `bind` | Задать this; bind — новая функция |
| Прототип | `[[Prototype]]` / `__proto__`; `Object.create` |
| `class` extends | Сахар над прототипами; `super` |
| `instanceof` / `isPrototypeOf` | Цепочка прототипов |
| Приватные поля | `#field` в class; модуль/замыкание как альтернатива |
| Каррирование / partial | Функция возвращает функцию с зафиксированными args |
