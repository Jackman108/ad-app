# Алгоритмы Easy — только чтобы не слиться на скрининге

Не готовься как competitive programmer. Цель: 15–20 задач, уметь объяснить.

## Темы

1. Массив: два указателя, sliding window  
2. Hash map: частота, two sum  
3. Строки: reverse, anagram  
4. Стек: valid parentheses  
5. BFS/DFS на дереве — опционально  

## Набор (LeetCode / аналоги)

- Two Sum  
- Valid Parentheses  
- Best Time to Buy and Sell Stock (easy)  
- Reverse Linked List (если спросят структуры)  
- Maximum Subarray (Kadane — опционально)  
- Merge Two Sorted Lists  
- Climbing Stairs  
- Binary Search  

## Шаблон ответа на собесе

1. Повтори задачу своими словами  
2. Пример на бумаге  
3. Наивный O(?) → улучшение  
4. Код → сложность время/память  

Язык кода: TypeScript/JavaScript.
