## Статусы (коротко)

- **отклик** — отправил  
- **ответ** — написали / пригласили  
- **скрин** — собес назначен / прошёл  
- **отказ** — с причиной если сказали  
- **оффер** — вилка и срок ответа  

## Фильтр вакансий

Брать: Next / React / Node / Nest / Prisma / Postgres / TypeScript.  
Не брать сейчас: PHP-only, 1С, «English B2+ daily».
